# scythe — Kinetic Video Pipeline

> Headless video compositing engine. Drop videos + images + audio → get brutalist, beat-synced MP4.

## Quick Start

```bash
# 1. Install dependencies (once)
./scripts/install_deps.sh

# 2. Create a project
./bootstrap.sh my-video

# 3. Drop your assets
cp ~/Downloads/soundtrack.mp3 projects/my-video/audio/
cp ~/Downloads/voiceover.wav projects/my-video/audio/   # optional
cp ~/clips/*.mp4 projects/my-video/raw_footage/
cp ~/logo.png projects/my-video/overlays/

# 4. Configure style (optional — edit projects/my-video/config.json)
#    { "preset": "vertical", "font": "LiberationSerif-Bold", "font_size": 72 }

# 5. Generate a cut-list
#    Feed prompts/brutalist-video-prompt.md to any LLM (Claude, ChatGPT, etc.)
#    Save the JSON output as projects/my-video/prompts/cutlist.json

# 6. Render
./render.sh projects/my-video
#    or: python main.py --project projects/my-video
```

## What It Does

1. Ingests your video clips, images, and audio
2. Reads a JSON cut-list defining frame-by-frame edits
3. Applies brutalist filters (monochrome crush, chromatic aberration, film grain)
4. Layers text overlays with configurable fonts
5. Mixes soundtrack + voiceover (soundtrack auto-ducked under VO)
6. Outputs H.264 MP4 with universal playback

## Project Structure

```
projects/my-video/
├── config.json       # Style: resolution, font, audio offset
├── audio/            # soundtrack.mp3 + voiceover.wav
├── prompts/          # cutlist.json (generated by LLM)
├── raw_footage/      # Your video clips + images
├── overlays/         # Logos, textures, grids
└── output/           # render.mp4
```

## config.json

```json
{
  "preset": "vertical",
  "resolution": [1080, 1920],
  "fps": 30,
  "font": "LiberationSerif-Bold",
  "font_size": 72,
  "stroke_width": 4,
  "stroke_color": "black",
  "text_color": "white",
  "audio_offset": 0.0
}
```

### Presets

| Preset | Resolution | Use Case |
|--------|-----------|----------|
| `vertical` | 1080×1920 | Shorts, Reels, TikTok |
| `widescreen` | 1920×1080 | YouTube, trailers |
| `square` | 1080×1080 | Instagram feed |
| `story` | 1080×1920 | Sans-serif, softer branding |
| `cinematic` | 1920×1080 | Large serif, dramatic |

### CLI Overrides

```bash
python main.py --project projects/my-video --resolution 1920x1080 --font LiberationSans-Bold --font-size 52
./render.sh projects/my-video --resolution 1920x1080 --audio-offset 40
```

## Ingestion Scripts

| Script | Purpose |
|--------|---------|
| `./ingest.sh projects/name` | Master orchestrator (scaffold + fetch all) |
| `scripts/fetch_audio.sh <dir> [query]` | yt-dlp extracts 5 royalty-free WAVs |
| `scripts/fetch_video.sh <dir> [ia_id]` | Internet Archive public domain films |
| `scripts/fetch_images.sh <dir> [url]` | wget Wikimedia Commons scrape |
| `scripts/preprocess.sh <dir>` | ffmpeg monochrome + contrast crush |

## Cut-List Format

The render engine reads `prompts/cutlist.json`:

```json
[
  {
    "start": 0.0,
    "end": 1.0,
    "phase": "hook",
    "text": "YOUR HEADLINE",
    "asset": "raw_footage/clip.mp4",
    "filter": "grayscale",
    "effect": "ken_burns_slow"
  },
  {
    "start": 5.0,
    "end": 5.08,
    "phase": "drop_transition",
    "text": null,
    "asset": null,
    "filter": "white_flash",
    "effect": "strobe"
  }
]
```

Generate cut-lists by feeding `prompts/brutalist-video-prompt.md` to Claude, ChatGPT, or any LLM.

### Filter Reference

| Filter | Effect |
|--------|--------|
| `grayscale` | Black & white |
| `color_invert` | Negative image |
| `high_contrast_green` | Crush + green accent |
| `high_contrast_red` | Crush + red accent |
| `white_flash` | Pure white frame |
| `chromatic_aberration` | RGB channel split |
| `film_grain` | 4% noise overlay |
| `color_crush` | Destroy midtones |

### Effect Reference

| Effect | Behavior |
|--------|----------|
| `ken_burns_slow` | 8% zoom over clip |
| `ken_burns_fast` | 15% zoom over clip |
| `snap_zoom` | Instant 30% zoom at midpoint |
| `strobe` | Flash frame |
| `word_flash` | Text timing effect |

## Audio Convention

- Files in `audio/` with `voice` or `vo.` in name → voiceover (full volume)
- Everything else → soundtrack (ducked to 30% under VO)
- Single file → plays as-is

## Dependencies

- **System**: `ffmpeg`, `wget`, `yt-dlp` (pacman / apt / brew)
- **Container**: Podman or Docker
- **Container provides**: Python 3.11, ffmpeg, jsonschema

## GPU Acceleration

Renders auto-detect hardware encoders with a dry-run check (0.2s null encode). No GPU access means libx264 CPU fallback, unchanged behavior.

```bash
# NVIDIA (requires nvidia-container-toolkit on the host)
./render.sh projects/my-video --gpu nvidia

# VAAPI or QSV (passes /dev/dri through)
./render.sh projects/my-video --gpu vaapi
./render.sh projects/my-video --gpu qsv
```

Diagnostics and overrides:

- `python main.py --check-gpu` prints the capability report (encoders, decoders, hwaccels, chosen encoder) and exits non-zero when the chosen encoder is not invokable.
- `NOX_GPU=off` forces CPU. `NOX_ENCODER=<name>` forces a specific encoder and aborts if it is not invokable.
- The VAAPI/QSV profiles assume `/dev/dri/renderD128`. Hosts with a different render node must use `NOX_ENCODER` or edit `src/gpu.py`.
